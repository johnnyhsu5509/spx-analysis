① MACD柱 <-20 + 地緣風險存在 = 禁止偏多

📌 新規則：MACD柱 <-15 且 地緣事件評分 >15/20 時
→ 自動將方向評級降為「中性」，移除所有突破做多策略
② 地緣因子：「脆弱停火」= 自動 18/20 滿分
原本地緣/總經佔 20%，「脆弱停火」給了約 13/20。但實際上只要存在「軍事威脅隨時可能升溫」的狀態， 就應該是接近滿分。一句 Trump 的話直接讓市場跌 2%+，這不是小風險。
📌 新規則：地緣評分標準
• 完全穩定 → 5/20
• 緊張但未升溫 → 12/20
• 脆弱停火 / 威脅言論 → 18/20（此次應用）
• 主動衝突 → 20/20（滿分）
③ 突破進場：量能是必要條件，非參考條件
分析已寫「量縮突破不可信」，但策略仍設「突破 7,480 進場」。 這造成矛盾：文字說不可信，策略卻讓人進場。 下次量能條件必須進入進場邏輯，而不只是文字提醒。
📌 新規則：突破做多必要條件（ALL 必須同時滿足）
