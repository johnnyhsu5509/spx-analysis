教訓一：判錯的根因是情景權重給偏，不是「禁折中」給錯
8/17 我把「廣度逆勢擴張」稱為最硬的偏多支柱，據此把方案C壓到 25%，同時低估了 MACD 柱已經連五縮。結果：廣度支柱兩個交易日內就瓦解（+0.82% → +0.31%，當日 -0.42%），而動能訊號如期兌現（第六度收窄）。
原因很清楚——廣度是同步指標（反映當下參與度，不預測明日），MACD 柱是動能導數（衰減具持續性）。用前者去對抗後者，方向就會判反。
若當時方案C給 35–40%，headline 會落在 50 上下而不是 44。→ 立 rule34 候補：動能訊號連續 3 日以上同向衰減時，同步型指標不得作為下修反向情景權重的主要依據。
教訓二：rule31 的第一份成績單要分開讀——掛單有效、方向判錯
回踩多改錨定前低 7,776 後確實成交了（8/14 的舊掛法 7,770 會差 6.31 點空掛）。成交之後虧損，是方向判斷的問題，不是掛單設計的問題。「接不到」和「判斷錯」是兩個獨立問題，不可混為一談。成交率由 25.6% 回升至 27.1%。

市場筆記

這次判錯值得記，因為錯得很有結構。
上週五我看到「指數跌但廣度漲」，把它讀成「賣壓只在權值股、中小型股在承接」，於是認定下方有支撐。這個讀法本身沒錯，錯的是把一個描述當下的指標，當成預測明天的依據。廣度告訴你此刻誰在買，不告訴你明天誰會賣。而 MACD 柱連續五天收窄講的是另一件事：推動的力氣在遞減——那是導數，有慣性，會延續。
兩個訊號打架時，該問的不是「哪個比較硬」，而是「哪個有時間延續性」。這次同步指標兩天就翻臉，動能指標如期兌現到第六天。
盤面上：⑤浪確認失敗，但 MA20 還在 7,600、完整多頭排列沒破。這是回檔，不是反轉——所以空單目標放 7,716 和 7,700 這種結構位，不放趨勢位。判斷轉空和押注崩盤是兩件事。
