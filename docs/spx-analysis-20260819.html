偏差分析：三個系統性發現

① 路徑風險 —— 兩道門檻都管不到的盲區（rule37 候補）
rule27 與 rule31 兩道進場距離門檻，確保的是「進場價離現價多遠」，完全不約束「價格會先往哪走」。 8/18 一根跳空低開同時廢掉兩張單：上方的反彈空 7,761 永遠接不到（差 47 點），下方的回踩多 7,730 卻在跳空瞬間成交後立即停損——這是掛單設計上最差的組合。
診斷：⑤浪衰竭確認的次日，「等對稱反彈的逆勢空」與「等回踩的順勢多」都建立在「價格會來回走」的假設上，而衰竭後的第一個下跌日常以跳空單邊展開。
候補規則：衰竭浪確認後首個交易日，策略表應納入「順跳空方向的追單（stop 單）」型態，並下調對稱逆勢單權重。
② 宏觀／類股資料連續三日空白（rule35 候補）
8/18 的兩大實際驅動——10Y 自 8/14 起連三日 ≥4.70 與 SOXX 8/18 崩 4.96%——在各自的分析當下都是已收盤、可直接取得的日線資料，不需要期貨。 但 8/17、8/18 兩份分析把整段 macro_layer 標記為【待補】，把「沒跑 check_es.py」誤等同於「沒有宏觀資料」，導致類股／宏觀維度空白三個交易日，8/18 的分析對半導體崩跌毫無預警。
修正方向：fetch_today.py 納入 SOXX/SMH/QQQ/RSP 與 10Y 的日線收盤；期貨層（ES/NQ）才是 check_es.py 的專屬職責。
③ RSI 口徑陷阱：指標讀數與當日方向相反（rule36 候補）
腳本使用 Cutler RSI（簡單 14 日均）。當一根大幅單日變動滑出 14 日窗口時，會產生與當日漲跌方向相反的假訊號。
8/18 實例：指數 -0.69%，Cutler RSI 卻由 70.77 升至 76.75（因 7/29 的 -112.63 滑出窗口）。若照 face value 讀成「超買加劇」，權重 25% 的過熱度因子會完全誤判。
同期 Wilder RSI：67.36 → 65.90 → 61.50 → 56.20（四日連降）才是真實動能。
規則：RSI 變動方向與當日漲跌方向相反時，必須以 Wilder RSI 複核後才可寫入分析，報告並列兩個口徑。
